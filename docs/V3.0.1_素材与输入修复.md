## 2. 修复“移动时按跳跃变成原地跳”

根因是场景层额外监听 `pointerupoutside` 并调用 `releaseAll()`。真实多指触控中，一根手指的 Phaser outside/up 生命周期有机会清掉另一根仍按住的移动指针。

处理：

1. 移除 `LevelScene` 的 `pointerupoutside -> releaseAll()`；
2. 保留 `InputSystem` 的 pointerId 独立所有权；
3. 每个触摸按钮只释放自己的 pointer，不再释放全部输入；
4. `pointerdown / pointerup / pointercancel` 在 DOM 控件层阻止传播，避免和 Phaser Canvas 的同一触摸生命周期串扰；
5. window blur / visibilitychange / pagehide 仍保留 `releaseAll()`，避免切后台卡键。

实测：

- 右方向保持时按跳跃：起跳帧 `vx = 230`，不是 0；
- 松开跳跃指、仍按住右方向：空中 `vx = 230`；
- 键盘 `→ + Space` 同样保持横向速度；
- 双指 pointer 数量从 2 -> 松跳跃后 1 -> 松移动后 0，互不误清。
