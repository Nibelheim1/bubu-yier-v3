# 布布一二：去见你的小幸福 V3 重做说明

本次 V3 在 V2.1 基础上，结合新的示意图方向进行了整包重做，重点不是“微调数值”，而是把体验从温柔 demo 拉到更像一款完整小游戏。

## 核心改动

### 1. 前端呈现重做
- 重做封面、角色页、路线图、相册页、结算页文案与布局。
- 接入新的示意图作为界面预览图：封面、路线图、相册、三关封面图。
- 角色选择说明改为玩家语言：
  - 怕跳不过去选一二；
  - 想稳拿 Perfect、刷连击选布布。

### 2. 三关节奏差异化
- 重新生成三张关卡地图。
- 提前首个检查点，避免早期掉坑直接回起点的高挫败。
- 调整三关地形轮廓：
  - 城市：整体更平顺，强调借公交/纸箱/高架前进；
  - 乐园：更高低起伏，强调弹跳与连锁；
  - 星空：更明显的台阶与坡道节奏，强调点亮与探索。
- 调整各关检查点位置，使呼吸节奏不再一致。

### 3. 摄影挑战体验优化
- 挑战入口整体下调，触发更宽松。
- HUD 文案明确提示摄影小路与发光相机的意义。
- 相册页明确告知“照片不在主线终点，而在离主路不远的摄影小路里”。
- 挑战失败提示文案更直白：失败不扣心，可立即重试。

### 4. 移动端体验优化
- 旋转提示不再强制拦截，新增“仍然进入”。
- 触控按钮放大，移动端键位提示隐藏，避免文字过小。

## 构建与验证
- 已重新生成 maps。
- 已通过全部自动化测试（30/30）。
- 已重新构建 dist，可直接离线运行。
