# 布布一二 · 去见你的小幸福 V2

一个可本地运行、可继续编辑、已生成 `dist/` 的 Phaser 3 横版 H5 游戏。

本次交付依据上传的《V2 完整改版设计文档》重建。原上传包只有压缩构建产物，因此保留原 Phaser 引擎与角色素材，将游戏逻辑重写为模块化源码，而不是继续修改旧的 `index-*.js`。

## 先玩起来

### Windows

电脑已安装 Node.js 18 或以上时，双击根目录 **`启动试玩.bat`**，然后访问终端显示的本地地址。

### 命令行

在本项目目录执行：

```bash
node scripts/serve.mjs
```

浏览器打开：

```text
http://localhost:4173
```

**不用执行 `npm install`，不需要 API Key，也不需要外部 CDN。** 引擎、图片、地图均随包提供。

不要直接双击 `index.html`：本工程使用 ES Modules，需通过 HTTP 服务加载。这里的“无需联网”指本地服务器可以在无互联网的环境下运行，不代表已经实现 PWA 离线安装。

若端口被占用，设置 `PORT` 环境变量后启动，例如 Windows：

```bat
set PORT=4174
node scripts/serve.mjs
```

## 操作

键盘：方向键左右 / A、D 移动；空格 / 上方向键 / W 跳跃；Esc 暂停、继续。

手机：左下角左右按钮，右下角跳跃按钮，支持双指同时操作。竖屏显示横屏提示；“横屏 / 全屏”按钮会尝试使用浏览器支持的能力，不强制通过 CSS 旋转坐标。

长按跳跃更高，松开跳跃更低。一二在空中松开后再按可二段跳；布布没有二段跳，但 Perfect 区更宽、Combo 多保留 0.6 秒。

## 本次可以玩到什么

| 内容 | 实现 |
|---|---|
| 三段旅程 | 城市借物、乐园弹跳、星空点亮；三张不同地形地图 |
| 每关内容 | 8 个模块、20 个小幸福、3 张照片、3 个检查点、10 个指定 Perfect 落点 |
| 幸福连击 | 收集、Perfect、指定机关接力计入；受伤/超时断连；暂停冻结 |
| 高低路线 | 摄影小路和奖励路可跳过；失误优先回到主路 |
| 照片挑战 | 9 个实际多步骤挑战，不是碰到相机就获得 |
| 复玩目标 | 每关 3 徽章、个人时间/连击/小幸福纪录、角色独立纪录 |
| 情绪回报 | 终点重逢、相册、章节纪念卡、集齐 9 张后的最终合影和特别封面 |
| 记录管理 | V1→V2 迁移；导出/恢复 JSON 备份；照片获得时即时保存 |

普通伤害只扣心、击退；掉落回检查点；心情清空时恢复三心并回最近检查点，不整关重开。摄影挑战失败只重试挑战，不扣心。

## 修改与重新构建

```bash
npm run dev       # 直接预览 src/ 与 public/，修改后刷新浏览器
npm run validate  # 检查 Tiled 对象、数量、引用、主线几何边界
npm test          # 30 项 Node 单元/数据测试
npm run build     # 验证地图并重建 dist/
npm run preview   # 预览构建后的 dist/
```

地图实际加载文件位于 `public/assets/maps/`，可以用 Tiled 编辑。`scripts/generate-maps.mjs` 是本次地图的可重现生成源；**运行 `npm run maps` 会覆盖手工改过的三个地图 JSON**。人工编辑地图之后，只运行 validate/build，不要误运行 maps。

## 发布目录

使用另行提供的 **`BubuYier_V2_TapTap上传包.zip`**，或把 `dist/` 的**内部文件**打包。

压缩包根目录应直接看见 `index.html`、`src/`、`vendor/`、`assets/`；不要再套一层 `dist/`。

这是可供平台验收的静态 H5 包，**不等于已在 TapTap 上传、审核或真机验收**。此次未接入平台广告、支付、账号、排行榜或云存档 SDK。

## 存档说明

V2 存储键为 `bubu-yier-platformer:v2`。首次没有 V2 存档时，会尝试读取同一浏览器、同一网站来源下的 `bubu-yier-platformer:v1`。迁移后不删除旧键。

换网址、端口、浏览器或清除网站数据不会自动带走存档。设置中可导出和恢复 JSON 备份；备份包含照片解锁 ID、纪录和设置，不包含截图缩略图。缩略图缺失时使用章节插图替代，不影响已获得照片。

浏览器禁止本地存储或空间不足时，继续使用内存记录，并在设置里提示。关闭页面前需导出备份。

## 验证范围

30 项单元/数据测试通过；2 角色 × 3 主路线的 6 组自动操作通关通过；2 角色 × 9 照片挑战的 18 组局部通关通过；14 项运行时边界回归通过。

照片测试先将角色放到挑战入口，再使用实际移动、跳跃与物理完成挑战；不注入“挑战成功”事件。主路线测试从正常出生点连续操作到终点，不进行中途传送。

测试使用桌面 Chromium。30/20 更新率测试验证的是模拟低更新率下的落台，不是低端手机性能实测。Android、iOS、平台 WebView、刘海屏、真机音频和平台发布仍需实际设备验收。详情见 `docs/测试报告.md`。

## 交付边界

V2.1 无限模式未加入；不加入战斗、武器、复杂货币、强制广告。动态箱体采用可预测的移动踏板，而非自由推动、堆叠或真实翻滚刚体。

熟练自动控制器的主路通关时间约 39–41 秒；原文档的 90–150 秒初玩时长尚未通过真人测试验证。本次优先保持流畅，不靠空跑加长地图。照片、高路和全收集是额外的探索目标；更细的角色平衡和徽章阈值仍适合根据真实试玩记录继续调优。
