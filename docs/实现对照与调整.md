# V2 实现对照与主动调整

本文件区分：原设计基线要求、实际实现、主动调整及未验证部分。设计基线原文保留在本目录，不用新增说明覆盖原文。

## 1. 工程与稳定性

原包只有构建结果。本次继续采用包内 Phaser 3.90.0，所有游戏规则进入新 `src/` 模块。没有把压缩引擎改成新的游戏主逻辑。

与文档建议的 Vite + TypeScript 不同，本次采用原生 JavaScript ES Modules 与 Node 内置模块构建。原因是保留清晰源码的同时，让交付不依赖 npm 下载、插件版本和网络服务。没有构建依赖，`build` 校验后复制确定的源文件和素材。

移动平台使用 Arcade 速度、不可推动物体和摩擦系数，不使用 Tween 更改碰撞位置。单向碰撞使用上一物理步 bottom、平台 top 和相对下落速度。Perfect 增加“真正离地超过 100ms 且有超过 16px 垂直行程”的条件，过滤平台换向时的微小接触变化。

触屏按 pointerId 记录拥有的操作；全局释放、取消、失焦、页面隐藏、旋转、暂停会清理状态。一个手指松开不会取消另一个手指的跳跃。角色受伤闪烁结束强制恢复 alpha=1。

## 2. 核心玩法

保留三类操作和原重力基线。两个角色同速 230，布布 jump=-515、一二=-505；布布 Perfect 基础宽度 45%，一二 32%，移动平台额外增加 8 个百分点。一二空中额外跳一次，力度约为原跳的 92%。

Combo：布布 3.8 秒、一二 3.2 秒。拾取、Perfect、有效机关动作或照片要求的指定普通落台可加连击。普通落地不主动断连，受伤、掉落、超时和挑战重试会断连。暂停冻结逻辑计时。

防止原地刷分：连续回到同一个 Perfect 台不会反复增加 Combo；同一关中普通弹簧的首次奖励只记一次，照片挑战重新尝试时重置其专属弹点奖励。计分并不增加基础速度，避免破坏几何可达性。

文档的检查点分段表有两个检查点、总预算又要求三个。本次统一每关三个，约 25%、50%、75%，顺序读取 Tiled 属性，触发恢复 1 心。

## 3. 三张关卡

每张为 192×16、48px 网格，8 个命名模块；20 个小幸福、3 张照片、3 个检查点、10 个指定 Perfect 区。地形轮廓分别生成，机关组合也不同，不复用旧三关近似一致的地形。

### 下班冲冲冲

低处街道与高处雨棚/公交/屋顶结合。水洼只减速，传送带改变水平移动，移动纸箱是踏板，滑板可乘坐且侧撞会伤害。箱体不使用自由滚动或堆叠刚体，这是一项稳定性取舍。

### 乐园蹦蹦跳

蹦床、红黄蓝气球接力、错相升降木马、泡泡池、往返软锤。气球不是墙体，每次空中流程避免同一个气球重复弹射。空中五事件挑战通过弹簧、气球和星点构成，不额外占用主关卡的 20 个小幸福总数。

### 星空去见你

风区降低净重力并调整空中控制；开关真正激活星桥。主路星桥 4.5 秒有效、末 1 秒闪烁，站在到期平台上的角色获得 300ms 宽限。开关可离开后再次进入触发。

摄影小路中的树冠和灯串属于自己的平台组，使用较长的窗口，不沿用主路 4.5 秒的高压时限。挑战失败清理自己的状态，不永久关闭关键入口。

## 4. 九张照片的实际条件

| 关卡 | 照片 | 实际完成条件 |
|---|---|---|
| 城市 | 晚霞车站 | 依次落上三个公交/站台，中途不落地，到摄影台 |
| 城市 | 纸箱小屋 | 移动箱体 → 雨棚 → 屋顶 → 摄影台 |
| 城市 | 下班路灯 | 依次点亮三盏灯，再到摄影台 |
| 乐园 | 彩虹气球 | 红 → 黄 → 蓝气球，中途不落地，再落到摄影台 |
| 乐园 | 旋转木马 | 依次落上三个错相移动木马，第三个落点需要 Perfect |
| 乐园 | 乐园合影 | 单条空中接力获得至少五个不同事件，再到摄影台 |
| 星空 | 萤火虫树 | 依次点亮四只萤火虫，逐步开启树冠落脚点，到摄影台 |
| 星空 | 流星山坡 | 12 秒内依次收集五个专属星点，到山坡摄影台 |
| 星空 | 露营灯串 | 点亮三盏营灯，各自开启下一段平台，到最终摄影位 |

默认时限 12 秒，木马和萤火虫树为 14 秒。窗口比部分推荐基线宽，优先可读性与可重试性。

挑战超时、落回地面或离开摄影范围后，回该挑战入口，1 秒后可以再尝试，不扣心。文档既要求“掉回安全路”又要求“立即重试”，本次将两者分开：普通高路失误自然掉回安全路；摄影中的明确失败回摄影入口。向下离开入口即可跳过，不强制做照片。

已解锁照片在重玩时仍必须重新完成挑战，才播放此次成功演出；不会仅凭存档已有照片自动成功。旧照片迁移保留，不要求老玩家重做。

## 5. 进度与情绪回报

小幸福是单局表现，最高纪录保存数值；照片、徽章永久保存。各角色分别记录时间、连击、小幸福、心情和无伤结果。回血到满心不等于无伤。

相册有实际摄影截图缩略图；无缩略图时使用章节插图。每章集齐三张可导出章节纪念卡；九张齐全后开启特别封面和单独的最终合影导出。结算另可导出该次成绩纪念卡。

额外加入 JSON 备份恢复，避免只有“导出”没有入口恢复。缩略图不进入 JSON，减小备份体积。所有记录本地保存，没有外部统计或云服务。

## 6. 仍需后续真人/真机验证的目标

六组自动主路控制的通关约为 39–41 秒，不能把它当作普通玩家首次通关时间；也不能据此声称已经达到原设计 90–150 秒的新手目标。

两角色的全部挑战局部可达性已通过自动操作，但“平均通关效率接近”“连玩五次仍有吸引力”“首次主动复玩率”等属于真人体验指标，本次没有伪造数据。全收集线路和 12/15/14 的心流徽章阈值也尚未进行完整人工调优验证。

V2.1 无限模式按设计留在后续；不加入文档明确排除的战斗、装备、复杂经济、联网 PVP 和强制广告。
